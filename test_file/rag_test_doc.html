一、实验目的

本实验基于卷积神经网络CNN完成花卉图像分类识别任务，属于计算机视觉基础深度学习实验。通过本次实验，学生需要掌握卷积神经网络基础结构、图像数据预处理流程、迁移学习训练方法、模型评估指标等核心内容。

  • 理解卷积层、池化层、全连接层的作用，掌握CNN图像分类基本流程；
  • 学会使用PyTorch框架加载图像数据集、构建数据增强流水线；
  • 掌握迁移学习方法，使用预训练模型ResNet快速完成花卉分类任务；
  • 学习划分训练集、验证集、测试集，使用准确率、混淆矩阵评估模型效果；
  • 能够分析欠拟合、过拟合现象，使用Dropout、数据增强、早停策略优化模型；
  • 独立完成模型推理，输入花卉图片输出类别与置信度，撰写实验总结。

二、实验预习要求

实验开始前，学生必须提前预习相关知识点，否则很难跟上实验进度。预习内容包括卷积神经网络原理、梯度下降、反向传播、迁移学习、图像数据增强方法。同时需要提前安装好Python环境以及深度学习依赖库，预习数据集结构，了解Flower数据集包含的花卉类别。预习时思考：为什么图像分类任务适合使用卷积神经网络？迁移学习相比从头训练模型有什么优势？

预习检查点：能够说出卷积、池化的作用；能区分训练集、验证集、测试集用途；知道过拟合的常见解决办法。

四、实验数据集介绍

本实验采用经典Flower17花卉数据集，该数据集是计算机视觉课程常用小型分类数据集，一共包含17类不同花卉，每一类花卉有80张图片，数据集总图片数量1360张。花卉种类包含郁金香、雏菊、玫瑰、水仙、风信子等。图片分辨率不统一，存在光照变化、角度变化、背景干扰，非常适合用来练习图像分类。

数据集目录结构规范要求：采用分类文件夹格式，每一类图片放入对应名称文件夹，方便torchvision的ImageFolder直接加载。实验时按照7:2:1划分：70%训练集、20%验证集、10%测试集。训练集用来更新网络权重；验证集在训练过程中监控精度，用来调整超参数；测试集全程不参与训练，只用来最终评估模型泛化能力。

数据集子集 占比 作用
训练集 train 70% 网络参数学习、反向传播更新权重
验证集 val 20% 调参、观察过拟合、早停判断
测试集 test 10% 最终模型泛化性能评估

五、实验原理

1.卷积神经网络CNN

卷积神经网络依靠卷积核提取图像底层、中层、高层特征：底层特征是边缘、线条、色块；中层特征是花瓣轮廓、纹理；高层特征是完整花卉形态。池化层用来降低特征图尺寸，减少参数量，提升特征鲁棒性。全连接层把二维特征图展平为一维向量，最后输出各个类别的概率。

2.迁移学习

在ImageNet大数据集上预训练好的ResNet已经学习到通用视觉特征，我们只需要替换最后一层分类头，在花卉数据集上微调。相比从零训练，迁移学习收敛更快、小数据集下不容易过拟合，是图像分类项目最常用方案。

3.数据增强

数据增强通过随机裁剪、随机翻转、随机旋转、亮度扰动等方式生成新样本，扩充数据集，抑制过拟合。测试集只做归一化、缩放，不使用随机增强，保证评估稳定。

4.损失函数与优化器

多分类任务使用交叉熵损失CrossEntropyLoss；优化器选用Adam，自适应学习率，收敛速度优于SGD。评价指标使用分类准确率Accuracy。

六、实验内容与详细步骤

  1. 数据集下载、解压，按照train/val/test整理文件夹结构；
  2. 编写数据增强transform，构建Dataset、DataLoader加载器；
  3. 加载预训练ResNet18，修改最后一层输出为17类；
  4. 定义损失函数、优化器，设置训练轮次epoch、batch size、学习率；
  5. 编写训练循环：前向传播、计算损失、反向传播、参数更新；每轮结束在验证集测试精度；
  6. 记录训练损失、验证精度，绘制loss-acc曲线；
  7. 训练完成后，在独立测试集上计算最终准确率；
  8. 单张图片推理：输入一张花卉图片，输出类别名称和置信度；
  9. 调整超参数（学习率、batch size、是否冻结主干网络）重复实验，对比结果；
  10. 记录实验现象，分析模型错误识别样本，撰写实验报告。
重要提醒：测试集数据绝对不能参与训练和调参，不能根据测试集结果修改网络和超参数，否则评估结果虚高，失去参考意义。

七、参考实验代码（PyTorch）

import torch import torch.nn as nn import torch.optim as optim from torchvision import datasets, transforms, models from torch.utils.data import DataLoader import matplotlib.pyplot as plt device = torch.device("cuda" if torch.cuda.is_available() else "cpu") print("使用设备：", device) # 数据预处理与增强 train_transform = transforms.Compose([ transforms.Resize((224,224)), transforms.RandomHorizontalFlip(p=0.5), transforms.RandomRotation(15), transforms.ToTensor(), transforms.Normalize([0.485,0.456,0.406],[0.229,0.224,0.225]) ]) val_test_transform = transforms.Compose([ transforms.Resize((224,224)), transforms.ToTensor(), transforms.Normalize([0.485,0.456,0.406],[0.229,0.224,0.225]) ]) # 加载数据集（修改为你本地路径） train_dataset = datasets.ImageFolder(root="./flower/train", transform=train_transform) val_dataset = datasets.ImageFolder(root="./flower/val", transform=val_test_transform) test_dataset = datasets.ImageFolder(root="./flower/test", transform=val_test_transform) train_loader = DataLoader(train_dataset, batch_size=16, shuffle=True) val_loader = DataLoader(val_dataset, batch_size=16, shuffle=False) test_loader = DataLoader(test_dataset, batch_size=16, shuffle=False) class_names = train_dataset.classes print("类别列表：", class_names) # 加载预训练ResNet18 model = models.resnet18(pretrained=True) in_features = model.fc.in_features model.fc = nn.Linear(in_features, 17) model = model.to(device) criterion = nn.CrossEntropyLoss() optimizer = optim.Adam(model.parameters(), lr=1e-4) def train_one_epoch(model, loader, criterion, opt, dev): model.train() total_loss = 0.0 correct = 0 total = 0 for imgs, labels in loader: imgs, labels = imgs.to(dev), labels.to(dev) opt.zero_grad() outputs = model(imgs) loss = criterion(outputs, labels) loss.backward() opt.step() total_loss += loss.item() _, pred = torch.max(outputs,1) correct += (pred == labels).sum().item() total += labels.size(0) return total_loss / len(loader), correct / total def val_one_epoch(model, loader, criterion, dev): model.eval() total_loss = 0.0 correct = 0 total = 0 with torch.no_grad(): for imgs, labels in loader: imgs, labels = imgs.to(dev), labels.to(dev) outputs = model(imgs) loss = criterion(outputs, labels) total_loss += loss.item() _, pred = torch.max(outputs,1) correct += (pred == labels).sum().item() total += labels.size(0) return total_loss / len(loader), correct / total num_epochs = 15 train_loss_list, val_acc_list = [], [] for epoch in range(num_epochs): tr_loss, tr_acc = train_one_epoch(model, train_loader, criterion, optimizer, device) va_loss, va_acc = val_one_epoch(model, val_loader, criterion, device) train_loss_list.append(tr_loss) val_acc_list.append(va_acc) print(f"Epoch [{epoch+1}/{num_epochs}] Train Loss:{tr_loss:.4f} Val Acc:{va_acc:.4f}") # 测试集评估 _, test_acc = val_one_epoch(model, test_loader, criterion, device) print(f"==== 测试集最终准确率：{test_acc:.4f} ====") # 保存模型 torch.save(model.state_dict(), "./flower_resnet18.pth") print("模型已保存")

八、实验结果记录与分析

训练过程中，需要记录每一轮训练损失、验证集准确率。正常情况下，训练损失逐步下降，验证准确率逐步上升，后期趋于平稳。如果训练集准确率很高、验证集准确率很低，说明模型发生过拟合，需要增加数据增强、添加Dropout、减少训练轮数、降低学习率。如果训练集准确率一直很低，属于欠拟合，可以增加训练轮次、调高学习率、检查数据集标注是否出错。

实验完成后，挑选几张识别正确、识别错误的样本截图放入报告。错误样本大多来自：花卉和背景高度混杂、光照过暗、同类花卉形态差异大、不同类别花卉外观高度相似。分析错误样本是实验报告得分重点。

九、常见报错与问题排查

  • RuntimeError: CUDA out of memory：显存不足，调小batch size，或者切换CPU运行；
  • ImageFolder读取不到图片：检查文件夹路径，图片必须放在二级分类文件夹内；
  • 准确率一直很低：检查归一化均值方差是否和预训练模型匹配、标签是否错乱；
  • loss不下降：学习率设置不合理，学习率过大震荡、过小收敛极慢；

十、实验思考题

  1. 为什么迁移学习在小数据集花卉识别任务中效果远好于从头训练CNN？
  2. 数据增强为什么能够缓解过拟合？测试集为什么不能使用随机增强？
  3. 如果新增3类花卉，怎么在已经训练好的模型上继续训练？
  4. 除了ResNet，还可以选用哪些适合图像分类的网络？各自特点是什么？
  5. 混淆矩阵可以提供哪些单纯准确率无法体现的信息？
